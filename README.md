# Учебные материалы по экономике

## Цель проекта
Собрать и систематизировать учебные материалы для студентов бакалавриата.

## Разделы
- Анализ данных в экономике
- Статистика
- Практические занятия
- Тесты и задания
- Решения задач

## План работы
1. Создать структуру материалов.
2. Добавить первые практические задания.
3. Проверить и обновлять документы.
